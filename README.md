# CSE332-Computer-Architecture--Design-Our-Own-CPU-and-Own-OS
This project implements a custom MIPS CPU in Verilog with simulation and testing using ModelSim and Ubuntu WSL. The CPU supports important MIPS instructions such as `JAL`, `JR`, `SLL`, and `SRL`, along with custom operations like `MIN`, `MAX`, and `MEAN`.Through this project, we gained practical experience in CPU architecture.
